## Follow-up pass (2026-09-07, three parallel agents, all merged)

- **Localization:** new `public` namespace (507 keys) in en/es/pt/ht; every customer-facing page (landing, pricing, booking, check-in, status, lookup, kiosk, virtual queue, mobile queue, shared header/footer) plus their toasts and RPC error messages now switch language. Pricing copy: "Spanish, Portuguese and Haitian Creole on all customer-facing pages (staff tools in English)". Closes F25.
- **Metrics:** `src/lib/dateRanges.ts` is the single definition of "today"; staff, admin, power-user and performance-report use it. Appointments Today = scheduled in the local day; Waiting Now = checked_in within 24 h (matches `public_queue_snapshot`); Served Today = completed by end_time; No-shows Today = no_show by updated_at. Closes F20, F34. Residual: the `staff-metrics` edge function still keys on `staff_id` (the dashboard sets `assigned_staff_id`), so the report's per-staff tab under-counts.
- **F36:** create/edit dialogs disable submit while saving and close before refetch. **F38:** undo marks the original action undone, is not itself undoable, and refreshes the queue immediately.
- **Rename:** no "Broward" left in `src/` (Brand* UI primitives, SiteHeader/SiteHero/SiteFooter, /design-system routes).
- **Lint:** 248 errors → 0 (38 warnings remain: exhaustive-deps and react-refresh); CI no longer uses `continue-on-error`. Deno edge functions are excluded from the browser ESLint config.
- **Data:** all E2E test customers/appointments removed (migration 20260907233000).

## Second follow-up pass (2026-09-07, three parallel agents, all merged)

- **Per-staff metrics:** the report's Staff tab no longer calls the `staff-metrics` edge function; `src/lib/staffMetrics.ts` aggregates the day's appointments in the browser keyed on `assigned_staff_id ?? staff_id` (the queue dashboard only ever sets the former, so per-staff served counts were always 0). Unit-tested. Admin "Open Locations" card states its definition; staff "Total Customers / All-time entries" renamed to "In Today's Queue / Arrived or resolved today", which is what it counts.
- **Performance:** `AuthProvider` was mounted twice (main.tsx and App.tsx) and re-fetched the role on every auth event — six `user_roles` requests per page load; now one, cached per user with a regression test. Staff/admin/power-user first paint no longer waits on `appointments?select=*` with three nested joins or `customers?select=*`; lists are shared via react-query keys with staleTime and fetched only by the tab that needs them. recharts moved out of the admin/power-user page chunks: initial payload /admin 1,233 KB → 776 KB, /power-user 1,235 KB → 753 KB. Three effects that re-ran on every render fixed.
- **PWA:** `registerType: 'autoUpdate'` + `skipWaiting`/`clientsClaim`/`cleanupOutdatedCaches`; the page reloads once when a new worker takes control (loop-guarded: one reload per page, max three per 30 s), also on a chunk preload error; hourly `update()` poll for kiosk/signage screens. No runtime caching, so Supabase requests never touch the worker. The cold-load 404 was the browser probing `/favicon.ico` at the origin root because `index.html` declared no icon link — fixed with explicit icon/apple-touch-icon/theme-color links. Stale `public/manifest.json` removed; `manifest.webmanifest` is installable (start_url/scope `./`, 192+512 maskable icons). `404.html` is now generated from the built `index.html` so deep links work under a sub-path or a domain root.
